# Git - git is distributed version control
## Version Control - we need to save our code, changes made everytime. if we save same file the old changes will get erased. everynew update will be new file. if we want to go back to previous version using version control we can go back to our old files at any given point of time.
### category - 1. local version control - local copy on machine.
#### 2. Centralized Version Control System (CVCS) - a centralized version system. other people can see it and get it.
#### 3. Distributed Version Control System (DVCS) - we have history, copies of commits, files on local as well as remote.

### Commands - 
#### `git init -b main` -> it will create empty git local repository with main branch.
#### `git status` -> it gives status of your project files.
