## Store Database Credentials on Server
1. Open Eclipse
2. Click on *Server*, Double click on Server which you are using.
3. Under *General Information* tab, click on *Open launch configuration*
4. Select *Environment* tab.
5. Click on *Add* button
6. Add your database key, values.
7. Click Apply
8. Click OK
9. Make sure that you added *.metadata/* and **.launch* added in .gitignore file.
